# Accessories

Track physical supporting hardware here:

- power supplies and UPS units
- storage, adapters, and enclosures
- USB hubs, docks, and cables
- network, Bluetooth, Zigbee, Z-Wave, and Thread adapters
- displays, cameras, cases, and cooling

Use one page per exact model. Record connector, power needs, driver/firmware, tested device, tested OS, and result. Add the relationship to [Compatibility](../COMPATIBILITY.md#accessories-and-sensors).
