# Flashing and recovery

| Tool | Target | Host OS |
|---|---|---|
| [ADB](adb.md) | Android devices | Linux, macOS, Windows |
| [Heimdall](heimdall.md) | Samsung devices | Record per tool version |
| [Odin](odin.md) | Samsung devices | Windows |
| [SamFW](samfw.md) | Samsung devices | Windows |
| [Image writers](../install-an-os.md#image-writers) | SD, USB, SSD | Varies |

Confirm the exact device, image, tool version, cable, and host OS before flashing.
