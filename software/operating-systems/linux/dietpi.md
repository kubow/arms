# DietPi

Lightweight Debian-based system for SBCs, small servers, native PCs, and virtual machines.

- [Supported hardware](https://dietpi.com/docs/hardware/)
- [Installation](https://dietpi.com/docs/install/)
- [Documentation](https://dietpi.com/docs/)

Board availability does not imply that DietPi maintains its kernel, GPU, Wi-Fi, audio, or other upstream hardware support.
