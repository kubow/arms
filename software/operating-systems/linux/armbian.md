## Identify a build

- compilation source: 
	- Lunar (Ubuntu)
	-  Sid (Debian)
- compilation variant:
	- minimal
	- CLI - server install ready
	- xfce - GUI


```shell
cat /etc/armbian-release  
lsmod  #list of loaded modules
```
